# NorthStar-Data-Analytics
### database and analytics project using Python, R, and MongoDB
============================================================

### NorthStar Urban Mobility — Data Analytics Project
#### Overview
This project analyses operational inefficiencies in NorthStar Urban Mobility using:
- Python (data cleaning & EDA)
- R (statistical analysis & SQL queries)
- MongoDB Atlas (NoSQL database design)
- Query Optimisation (indexing & performance tuning)

---

## Dataset Description
The dataset contains real-world complexities including:
- Inconsistent categorical values
- Missing data
- Cross-file relationships
- Customer complaints and incident records
- App event data for NoSQL modelling

---

## Project Structure

### 1. Python EDA
- Data cleaning and preprocessing
- Data integration across datasets
- Root cause analysis of failures
- Visualisations and insights

### 2. R Analytics
- SQL queries using sqldf
- Statistical analysis
- Correlation and trend analysis

### 3. MongoDB
- NoSQL schema design
- Embedded and referenced data modelling
- CRUD operations
- Aggregation pipelines
- Data visualisation

### 4. Query Optimisation
- Index creation
- Explain plan analysis
- Performance comparison
- Query optimisation justification

---

## Key Insights
- Failed deliveries are concentrated in specific hubs
- Customer complaints are strongly linked to delays
- Manual route overrides increase operational costs
- Data fragmentation reduces efficiency

---

## Technologies Used
- Python (Pandas, Matplotlib, Seaborn)
- R (sqldf, ggplot2)
- MongoDB Atlas (NoSQL Database)
- Google Colab
